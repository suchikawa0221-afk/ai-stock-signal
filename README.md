日本株・米国株を毎日自動で分析して、買い候補・売り/警戒候補を Telegram に通知する仕組みです。
**注文は一切しません。** 最終判断は自分で行います。

| 項目 | 内容 |
|---|---|
| 実行場所 | GitHub Actions（無料・PCの電源不要） |
| 株価データ | yfinance（Yahoo Finance の日足。無料・個人利用） |
| 分析 | MACD・RSI・25/75日移動平均・出来高（Pythonで計算） |
| AI分析 | Google Gemini 無料枠。候補銘柄だけ、業績・ニュース（Google検索）・リスクを評価 |
| 結果ページ | `results/最新_日本株.md`・`results/最新_米国株.md`（毎回上書き）、`results/archive/` に日付ごとに保存 |
| 履歴 | `data/signals.db`（SQLite）に毎回保存 |
| 通知 | Telegram（任意。Secrets 未登録なら通知せず結果ページだけ） |
| 仮想売買 | 買いシグナルの終値で仮想購入 → 売りシグナル/−5%/＋15%で仮想売却し、勝率・最大ドローダウンを記録 |

実行タイミング（平日）：
- 日本時間 16:00 … 日本株
- 日本時間 翌朝 7:30 … 米国株

※GitHub の定期実行は混雑時に数十分遅れることがあります。

## 判定ロジック（Ver.1）

スコア 100点満点：

| 項目 | 配点 | 加点条件 |
|---|---|---|
| トレンド | 30 | 終値 > 25日線 / 25日線 > 75日線 / 25日線が上向き（各10） |
| MACD | 30 | MACD > シグナル（15）、直近3日以内にゴールデンクロス（15） |
| RSI | 20 | 40〜65＝20、30〜40＝15、65〜70・30未満＝10、70以上＝0 |
| 出来高 | 20 | 平均比1.5倍以上で上昇＝20、1.2倍以上＝10 |

- **買い候補**：スコア75以上 かつ MACD がシグナルより上（AI任せにせず明確な条件と組み合わせ）
- **売り・警戒**：MACDデッドクロス / 25日線割れ / RSI70以上 / 大商いの下落 / 損切り・利確目安到達
- **監視**：スコア65〜74
- **警告**：バイオ株（`sector` が `bio`）・決算7日前以内・売られすぎ

### AI分析（Gemini 無料枠）
保有中・候補の銘柄を優先して、1回最大10銘柄をAIが評価します（監視銘柄が10以下なら全銘柄）。

| 項目 | 配点 |
|---|---|
| 業績（売上・利益の成長、財務、業績修正） | 25 |
| 材料（ニュース・新製品・提携・業界動向） | 15 |
| リスク（治験・FDA・決算・規制。10=安全） | 10 |

- **総合スコア** ＝ テクニカル × 0.5 ＋ AI（50点）
- AIだけで買いにはしません。テクニカルで買い候補になった銘柄を、AIが「弱気」または25/50点未満と判断したら「監視」に下げます。
- 逆に、テクニカルが75点に届かなくても、次をすべて満たせば「買い候補」に上げます：
  総合スコア72以上（`buy_total`）／テクニカル60以上（`buy_tech_min`）／MACDがシグナルより上／AIが弱気でない
- 総合64〜71でAIが弱気でない銘柄は「監視」に入ります。
- 結果ページの先頭に「⭐ 総合スコア上位」3銘柄を表示します。
- `GEMINI_API_KEY` が未登録、または無料枠の上限に達した日は、テクニカルだけで動きます。

75点は「上がる確率75%」という意味ではありません。数値は `config.json` で調整できます。
最初の1〜2か月は仮想売買の成績を見て、使えるかどうか検証してください。

## セットアップ手順

### 1. Telegram Bot を作る（5分）
1. Telegram で **@BotFather** を検索してトークを開く
2. `/newbot` → Botの表示名 → ユーザー名（末尾が `bot`）を送る
3. 表示された **トークン**（`123456:ABC...`）を控える
4. 作ったBotとのトークを開いて何か1通送る（例：`hi`）
5. ブラウザで次を開く（`<トークン>` を置き換え）
   `https://api.telegram.org/bot<トークン>/getUpdates`
6. 表示の中の `"chat":{"id":123456789` の数字が **チャットID**

### 2. GitHub にリポジトリを作る
1. GitHub アカウントを作成（無料）
2. 右上「＋」→ **New repository** → 名前 `ai-stock-signal`、**Private** を選んで作成
3. 「uploading an existing file」から、このフォルダの中身をすべてアップロード
   - `.github` フォルダはドラッグ＆ドロップで入れる（隠しフォルダなので見えない場合は、エクスプローラーの「表示」→「隠しファイル」をオン）

### 3. Secrets を登録
リポジトリの **Settings → Secrets and variables → Actions → New repository secret** で2つ登録：

| Name | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | 手順1のトークン |
| `TELEGRAM_CHAT_ID` | 手順1のチャットID |

### 4. 手動で動かしてテスト
1. **Actions** タブ → `daily-stock-signal` → **Run workflow** → `all` のまま実行
2. 1〜2分で緑のチェックになり、Telegram に結果が届けば完成
3. 失敗したら、赤い×をクリックするとエラー内容が見られます

以降は平日に自動で動きます。

## 銘柄を変える
`watchlist.csv` を編集（GitHub上で鉛筆マークから直接編集できます）。

| 列 | 内容 |
|---|---|
| ticker | 米国株はそのまま（`TWST`）、日本株は `証券コード.T`（`7203.T`） |
| name | 表示名 |
| market | `US` か `JP` |
| sector | バイオ株なら `bio`（イベントリスク警告が付く） |
| entry_price | **実際に保有している場合だけ** 取得単価。損切り−5%・利確＋15%の警告が出る |
| memo | 自由メモ |

10〜30銘柄を目安に。

## 設定を変える（config.json）
| キー | 意味 | 初期値 |
|---|---|---|
| buy_score | 買い候補のスコア | 75 |
| stop_loss_pct / take_profit_pct | 損切り / 利確の目安(%) | −5 / ＋15 |
| volume_surge | 出来高急増とみなす倍率 | 1.5 |
| notify_when_no_signal | シグナル無しの日も通知するか | true（慣れたら false 推奨） |
| show_news | 買い/売り候補に英語ニュース見出しを付ける | true |
| paper_trading | 仮想売買を記録する | true |

## 注意
- yfinance は Yahoo Finance の非公式ライブラリです。個人利用の範囲で使い、仕様変更で取得できなくなることがあります（その場合は通知の「取得エラー」に出ます）。
- 日足ベースのスイングトレード（数日〜数週間）向けです。デイトレードの判断には使えません。
- 仮想売買はシグナル当日の終値で約定した前提なので、実際より成績が良く見える傾向があります。
- 本システムの出力は売買の推奨ではありません。

## Gemini APIキーの取得（無料）
1. https://aistudio.google.com/apikey を開き、Googleアカウントでログイン
2. **Create API key** → 作成されたキーをコピー
3. GitHub の Settings → Secrets and variables → Actions に `GEMINI_API_KEY` として登録

※支払い情報（クレジットカード）は登録しないでください。登録しなければ無料枠を超えても課金されず、その日はAI分析が止まるだけです。
※無料枠では入力内容がGoogleのサービス改善に使われることがあります（銘柄名と公開情報だけなので問題になりにくい）。
